# Personal Portfolio Website

A modern, responsive multi-page portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, certifications, and contact information.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern dark-themed user interface
* Mobile-friendly hamburger navigation menu
* About Me section
* Skills section with categorized technical skills
* Projects showcase with project cards and previews
* Certifications section
* Contact page with glassmorphism design
* Social media and professional profile links
* Smooth hover effects and animations

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
* Responsive Web Design

## Pages

### Home

Introduction, profile section, and navigation.

### About

Personal introduction, education details, technical skills, and achievements.

### Skills

Showcases technical skills, tools, platforms, and technologies currently being learned.

### Projects

Includes:

* Student Learning Dashboard
* Online Book Store
* Quiz App
* To-Do List
* Personal Portfolio Website

### Contact

Glassmorphism contact section with:

* Email
* GitHub
* LinkedIn
* Professional networking button

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project folder

```bash
cd portfolio-website
```

3. Open `home.html` in your browser.
